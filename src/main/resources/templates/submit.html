Submit a run

Paste the JSON payload of a single experiment result. The server computes the canonical hash, records who submitted it and when, and (if you supply a batch) merges the payload's metric keys into the batch's shorthand mapping. Submitted content is immutable — resubmitting with the same _source.file creates a new version.

Error message

A batch groups related runs and enables shorthand metric resolution (e.g. accuracy instead of the full dot-path). Existing batches appear as suggestions; you can type a new name to create one.
