Submit a run

Paste JSON or upload a file. The server computes the canonical hash, records who submitted it and when, and (if you supply a batch) merges the payload's metric keys into the batch's shorthand mapping. Submitted content is immutable — resubmitting with the same _source.file creates a new version.

A batch groups related runs and enables shorthand metric resolution (e.g. accuracy instead of the full dot-path). Existing batches appear as suggestions; you can type a new name to create one.

Runs are append-only. To correct a mistake, submit a new version with the same _source.file; the old version stays in history.
