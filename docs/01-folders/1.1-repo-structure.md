# REPO STRUCTURE

```text
run-ledger/
│

│
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── com/runledger/
│   │   │       ├── RunLedgerApplication.java        ← Spring Boot entry point
│   │   │       │
│   │   │       ├── controller/
│   │   │       │   └── RunController.java          ← REST endpoints (POST & GET /api/runs)
│   │   │       │
│   │   │       ├── dto/
│   │   │       │   ├── RunRequest.java             ← Incoming JSON payload wrapper
│   │   │       │   └── RunResponse.java            ← Clean API response (id, payload, createdAt)
│   │   │       │
│   │   │       ├── entity/

│   │   │       │
│   │   │       ├── repository/
│   │   │       │   └── RunRepository.java          ← Spring Data JPA repository
│   │   │       │
│   │   │       └── exception/
│   │   │           └── GlobalExceptionHandler.java ← Centralized error handling
│   │   │
│   │   └── resources/
│   │       ├── application.yml                    ← DB config, JPA, Flyway settings
│   │       └── db/
│   │           └── migration/
│   │               └── V1__create_run_table.sql   ← Flyway schema migration
│   │
│   └── test/                                      ← Unit + integration tests (empty for now)
│
└── README.md                                      ← Project documentation
```
